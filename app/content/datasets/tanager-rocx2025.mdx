<Prose>
This dataset provides orthorectified true-color (RGB) imagery from **Tanager-1**, Planet's hyperspectral satellite, for the **ROCX 2025** application set. The 16 scenes were captured between July 4 and October 29, 2025 over selected sites.

The displayed layer is the `ortho_visual` product — a georeferenced and projected visual representation of each acquisition (a GeoTIFF version of the scene thumbnail). The underlying Tanager-1 core imagery products (radiance, surface reflectance hyperspectral cubes, and quicklooks) are also available as assets on each STAC item.
</Prose>
</Block>

<Block type='full'>
<Prose>
## The Tanager-1 Mission

Tanager-1 is a hyperspectral satellite operated by Planet Labs PBC, collecting imagery across hundreds of contiguous spectral bands. The Tanager STAC catalog organizes core imagery products into application-themed collections; this dataset replicates the **ROCX 2025** collection.
</Prose>

## Dataset Specifications

| Specification | Value |
|--------------|-------|
| **Displayed Product** | `ortho_visual` (orthorectified true-color RGB) |
| **Spatial Resolution** | ~30 m |
| **Temporal Extent** | 2025-07-04 – 2025-10-29 |
| **Scenes** | 16 |
| **Coordinate System** | UTM (per-scene, e.g. EPSG:32618) |
| **Platform** | Tanager-1 |
| **Instrument** | Hyperspectral imager |

Each STAC item also carries the full Tanager-1 core imagery products as additional assets: basic and orthorectified radiance and surface-reflectance hyperspectral cubes (HDF5), usable data masks, geolocation arrays, methane quicklooks, and a recent monthly mosaic.
</Prose>
